# 🛠️ Landing Page - Sistema CMMS

Esta é uma Landing Page moderna e responsiva desenvolvida para apresentar um sistema de **CMMS (Computerized Maintenance Management System)**. O foco do projeto foi criar uma interface profissional, intuitiva e focada em conversão para empresas de gestão de manutenção.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as bases fundamentais do desenvolvimento web, focando em performance e semântica:

* **HTML5:** Estruturação semântica de todos os elementos.
* **CSS3:** Estilização personalizada, utilizando **Flexbox** para o alinhamento de componentes.
* **Design Responsivo:** Adaptado para oferecer uma boa experiência em diferentes tamanhos de tela.

---

## 📋 Funcionalidades em Destaque

- **Navegação Intuitiva:** Menu estruturado para facilitar o acesso às informações do software.
- **Seção Hero Impactante:** Chamada principal clara com foco no valor do produto.
- **Lista de Benefícios:** Exibição organizada das vantagens de usar um CMMS (redução de custos, controle de ativos, etc).
- **Layout Clean:** Uso de espaços e tipografia que transmitem a seriedade que o setor industrial exige.
